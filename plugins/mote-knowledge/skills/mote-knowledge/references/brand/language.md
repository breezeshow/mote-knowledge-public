# Language we use

Mote copy uses the words buyers already use. "From" says where each term comes
from: the positioning review, our own sales calls and support emails, or both.

## Use

| Language | From | Use it for |
|---|---|---|
| IEP, 504 plan, accommodations | Both | Lead copy for special education. Customers say "IEP students", "504 population", "read aloud accommodations" |
| Access the curriculum, access to grade-level content | Both | The outcome. "Access" is the buyer's own word |
| Assistive technology | Review | The category name, the descriptor, search |
| Special education | Both | Navigation, page names, headlines |
| Dyslexia, ADHD, dysgraphia | Both | Naming needs. Dyslexia is Mote's biggest search topic |
| English Learners | Review (the federal term) | Every page; our standard term |
| English language proficiency, proficiency level | State tests (WIDA ACCESS, ELPAC, TELPAS, ELPA21) | Where an English Learner is in learning English. Every state tests it yearly (WIDA: Entering to Reaching). Never "language level" |
| Multilingual learners | Review | Friendlier teacher-facing copy |
| Dually identified students, English Learners with disabilities | Review | The bridge page and conference sessions |
| Newcomers, home language | Calls | English Learner pages and FAQs |
| Text to speech, speech to text, word prediction | Calls | Beside our feature names, e.g. "Read Aloud (text to speech)" |
| Testing accommodation | Calls | Assessment Mode copy |
| Pilot | Both | Every school and district call to action |
| UDL, Tier 1, MTSS | Review | Supporting copy on our pages, not the headline |

## English Learner terms vary by state

Buyers say emergent bilingual (Texas), ENL (New York), MLL (Massachusetts) or EL
(California). Our copy always says **English Learners**; the English Learners
page carries one line naming the others.

## Use with care

| Language | Rule |
|---|---|
| ELL, ESL, ENL, MLL, emergent bilingual | Only in the one synonyms line, FAQs and meta descriptions, so searches and AI answers match. Body copy says English Learners |
| IDEA, Title I, Title III | Explain IDEA in one sentence wherever it appears; buyers on our calls only ever named Title III |
| Inclusion | Only in the IDEA sense, never a headline |
| Neurodiversity | Parent and teacher content only |
| Read Aloud | Describe it as access to content, not as reading instruction |
| "Premium" | Customers call Unlimited this. Use once in the FAQ ("Unlimited, sometimes called premium"), never as a plan name |
| Read&Write | Only on the comparison and switching pages, written "Read&Write (Everway)" |

## Avoid

- Equity, DEI, belonging, culturally responsive.
- "Diverse learners".
- "Struggling readers" (customers say it; keep it in their quotes, never in our
  copy).
- "Literacy platform" as the lead, and "read, write & be heard" (retired; see
  [positioning.md](./positioning.md)).
- Product words customers never use: accessibilize, Creating mode, Play Page.
- Competitors' own lines.

# Security

Mote's security posture: infrastructure, encryption, internal controls, and
breach response. The authoritative source is
[mote.com/privacy](https://www.mote.com/privacy).

## Infrastructure

- **Cloud provider:** Amazon Web Services (AWS).
- **Region:** US West (Oregon).
- **Account data:** encrypted at rest.
- **Backups:** continuous, with point-in-time recovery.

## Encryption

- **In transit:** TLS v1.2 or higher for all connections.
- **At rest:** AES encryption, managed through AWS infrastructure.

## Internal security

- **Multi-factor authentication** required for all Mote staff.
- **Role-based access** on the principle of least privilege.
- **Background checks** for operational personnel.
- **Regular external penetration testing.**

## Breach response

- **No known data security breaches to date.**
- On suspicion of a breach, Mote runs an expedited assessment. If a breach is
  confirmed or reasonably likely, notice is given to affected parties and, for
  students, to designated school-district contacts. Notice includes the breach
  date, the types of information affected, a plain-language description,
  remediation steps, and a designated contact.
- Mote follows all applicable national, state, and local breach regulations.

## Infrastructure certifications (via AWS)

ISO 27001 · SOC 2 Type 2 · PCI DSS Level 1 · FISMA, held by AWS for the
infrastructure Mote runs on. See [compliance.md](./compliance.md) for the
company-level compliance set.

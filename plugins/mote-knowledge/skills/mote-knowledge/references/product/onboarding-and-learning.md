# Onboarding & Learning

**Description.** This covers how new users get started with Mote, and where
teachers learn to use it well:

- **Mote Explorer:** Mote's onboarding experience, a seven-level quest that walks a
  new user through every Mote feature and how to use it. Completing all seven levels
  earns Mote Explorer status, and it is for students and teachers alike.
- **Syd's teacher-tools walkthrough:** a guided walkthrough on the teacher's own
  dashboard, started from **Get Started with Mote's Teacher Tools**. Syd highlights
  each step in place across four lessons: creating a class, reading the **Class
  Dashboard**, setting **Student Feature Access**, and building a **Mote Vocab**
  list. Where Mote Explorer covers the student toolkit, this covers running a class.
- **Courses:** Mote runs courses at `app.mote.com/courses`, predominantly for
  teachers.
- **Video guides:** the "Getting Started with Mote" YouTube playlist:
  `youtube.com/playlist?list=PL28_-psho_6SYzuiRKaUQ8HuAjzQCjlxw`.

**Why it exists.** A powerful toolkit only helps if people can find their way into
it. Mote Explorer takes a new user (student or teacher) through every feature, and
the courses, PD sessions, and videos take teachers from "installed" to genuinely
confident.

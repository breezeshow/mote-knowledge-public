# Mote Chrome Extension

**Description.** The Mote Chrome Extension is Mote's core product. It sits on every
student and teacher's device, and it does two jobs. For students, clicking it opens
the **Mote Sidebar**, a panel holding the reading, writing, and creating tools, which
travels with them across any webpage. For teachers, it adds Mote directly into Google
Workspace, so lessons can be made accessible from inside Docs, Slides, Forms, and
Classroom rather than in a separate tool.

**Naming.** The extension is the product; the **Mote Sidebar** is the panel it opens.
Both names are current. Write "Mote Sidebar" in full, never a bare "Sidebar" or
"sidebar", and never "toolbar". See
[`../brand/terminology.md`](../brand/terminology.md).

## What students get: the Mote Sidebar

The Mote Sidebar is fast, responsive, and non-intrusive: it can be minimized or
expanded, and placed horizontally or vertically to suit the user. Its tools are
organized into three modes (**Reading**, **Writing**, and **Creating**) chosen from
the mode selector at the top of the panel.

- **Reading Mode:** [Play Page](./features/read-aloud.md) ·
  [Select Area to Read](./features/read-aloud.md) ·
  [Translation](./features/webpage-translation.md) ·
  [Highlighter](./features/highlighter.md) ·
  [Screen Mask](./features/screen-mask.md) ·
  [Dictionary](./features/dictionary.md)
- **Writing Mode:** [Play Page](./features/read-aloud.md) *(the same Read Aloud
  Play Page, here so students can listen back to what they have written)* ·
  [Text Prediction](./features/text-prediction.md) ·
  [Speech to Text](./features/speech-to-text.md) ·
  [Review My Writing](./writing-review.md)
- **Creating Mode:** [Voice Recording](./features/audio-creation.md) ·
  [Audio Generation](./features/audio-creation.md) ·
  [Audio Upload](./features/audio-creation.md) ·
  [My Content](./platform.md) *(the content library)*
- **Focus Mode** is also chosen from the mode selector, but it isn't a tool mode
  like the other three. Instead of offering a toolset, it strips the page back to
  its core content. See [Focus Mode](./features/focus-mode.md).

Some tools also belong to other products and are documented there: **My Content**
opens the content library, which lives with [Mote Platform](./platform.md).

## What teachers get: accessible material in a few clicks

The extension is not only a student toolkit. It lets a teacher make existing
material accessible without rebuilding it:

- **Add Read Aloud and Translation to a Google Form in one click**, including on
  Google Forms quizzes.
- **Record spoken instructions on a Google Slide**, as embedded voice notes for
  directions.
- **Record spoken instructions in Google Classroom**, right where students collect
  their work.
- **Give voice feedback in Google Docs**, and in Canvas SpeedGrader.
- **Control class and student feature access** through Teacher Feature Controls, so
  a class or an individual student sees the tools the teacher intends. See
  [Mote Platform](./platform.md).

## Where it works

| Surface | What Mote adds |
|---|---|
| Google Docs | Text Prediction as students write, Read Aloud to listen back, and voice feedback from teachers |
| Google Slides | Embedded voice notes for directions, plus Dictionary and Read Aloud, including Read Aloud on graphics and images |
| Google Forms | Translation and Read Aloud added in one click, quizzes included |
| Google Classroom | Spoken instructions recorded where students collect their work |
| Any webpage | Every Mote Sidebar tool works on any page students visit |
| PDFs | Click **Open with Mote** on any PDF to use the full toolkit, powered by [Mote PDF](./mote-pdf.md) |
| Reading apps | Read Aloud works in **Sora** and **Epic**, so students keep the same reading accommodations there |

## Voice messaging and audio

Mote began as a voice-messaging tool, and those capabilities are now part of the
Chrome Extension rather than a separate product (they were previously grouped as
"Mote Classic", a name that is retired):

- **[Mote Feedback Workflow](./features/feedback-workflow.md):** voice feedback in
  Google Docs, Classroom, and Canvas, with a re-usable comment bank (Motebook),
  two-way Loops, and engagement tracking.
- **[Embedded Voice Recorder](./features/embedded-voice-recorder.md):** Mote's
  recorder inside Google Workspace, Gmail, and other apps.
- **[Online Audio Recorder](./features/online-audio-recorder.md):** a
  browser-based recorder at `mote.com/record`. Note this one needs no extension
  installed, so it is reachable without the Chrome Extension.
- **[Mote Pages](./features/mote-pages.md):** shareable, automatically transcribed
  pages for short-form audio.

A voice message carries warmth, tone, and nuance that typed text can't, and it is
faster to give. That strength is retained, embedded in the everyday classroom
tools rather than sold separately.

## How to use it

Click the Mote extension icon to open the Mote Sidebar. Use the mode selector at the
top to switch between Reading, Writing, and Creating Mode; each mode shows its own
set of tools. Focus Mode is chosen from the same selector, where available. The panel
can be rotated vertically or horizontally, or minimized on the page.

**Why it exists.** Accessibility tools usually come scattered: one extension for
reading, another for writing, another for translation, each with its own setup. The
Mote Chrome Extension puts a student's whole toolkit in one panel that follows them
across every webpage and document, so support is always a click away rather than
something to assemble.

**Where to get it.** The Chrome Web Store. On managed Chromebooks, an IT admin can
push Mote to every student device from the Google Admin console, so nobody has to
install it themselves. Users should pin it to the Chrome toolbar so it is one click
away on every page.

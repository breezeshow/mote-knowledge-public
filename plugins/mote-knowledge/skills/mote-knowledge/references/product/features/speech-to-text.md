# Speech to Text

**Description.** Speech to Text turns spoken words into written text. It supports
dictation in multiple languages with real-time transcription, so students can get
their ideas down by speaking instead of typing.

**How to use it.** Open the Mote Chrome Extension and go to **Writing Mode**, then choose
the Voice Typing icon (the middle button). Start talking to generate text; you can
pause, cancel, confirm, or change language while speaking. When you're done, either
copy the text or drag and drop it into a text field.

**Why it exists.** Dictation is only useful if the text comes out clean. Mote's
Speech to Text recognizes the shape of natural speech (pauses, ums, ahs, false
starts) and leaves them out, so what reaches the page reads like writing, not a raw
transcript. It works in multiple languages, in real time, and the finished text can
go into *any* text field across the web, so dictation isn't locked to one app.

**Where to find it.** The [Mote Chrome Extension](../chrome-extension.md) (Chrome extension); the
dictated text can be copied or dragged into any text field across the web, such as
Google Docs, Forms, Slides, or Wakelet.

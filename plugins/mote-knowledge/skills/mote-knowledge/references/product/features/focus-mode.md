# Focus Mode

**Description.** Focus Mode strips a webpage back to its core content (removing
ads, sidebars, and visual clutter) so what's left is a clean, distraction-free
reading space.

**How to use it.** Open a page and open the Mote Chrome Extension. If a green dot shows on
the mode icon, Focus Mode is available for that page. Click the top icon and select
Focus Mode.

**Why it exists.** Cluttered pages (ads, sidebars, pop-ups) derail readers who
can't easily filter signal from noise. Focus Mode strips all of that away, and,
crucially, every other Chrome Extension tool still works on top of the cleaned-up page. The
student gets a page with the distractions removed *and* the full set of Mote's
accessibility tools (Read Aloud, Screen Mask, Highlighter) usable on it together.

**Where to find it.** The [Mote Chrome Extension](../chrome-extension.md) (Chrome extension).

**Good to know** *(surface when relevant).* Focus Mode works on article-style pages
(news sites, blogs, educational resources), not every webpage. The green dot on the
mode icon shows when it's available.

# Highlight Notes

**Description.** Every time a student makes a highlight with the
[Highlighter](./highlighter.md), they have the option to type a note to go with it.
The note is a place to record why the passage was marked: the context behind the
highlight, or anything that will help them remember it later.

**Notes are always attached to a highlight.** There is no free-standing note in Mote;
a note exists as part of the highlight it belongs to.

**Where notes surface.**

- On the [My Annotations](./my-annotations.md) page, alongside the highlight they
  belong to.
- In a Google Doc built by **Export Highlights to Google Docs**. Exporting a page's
  highlights carries the notes across with them.

**Why it exists.** A highlight records *that* a passage mattered. By the time a
student comes back to it, the color on its own rarely tells them why. Letting them
type the reason at the moment they mark it keeps the thinking attached to the text,
which is exactly what usually gets lost between reading and writing. For a student
who finds extended writing hard, a short note at the point of reading is also far
more achievable than reconstructing the argument later.

**How to use it.** Highlight a passage in Reading Mode as usual, then type the note
when the option to add one appears with the highlight.

**Where to find it.** Reading Mode in the Mote Sidebar, as part of the
[Highlighter](./highlighter.md).
